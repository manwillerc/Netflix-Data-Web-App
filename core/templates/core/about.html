About This Project

This application is built as a full-stack data-driven platform using Django and SQLite. It features a data transformation pipeline that imports, cleans, and loads structured data into the database.

The system supports full CRUD functionality, allowing users to create, read, update, and delete records efficiently.

It also includes interactive analytical dashboards powered by Chart.js, which visualize key business and user statistics.

In addition, the platform integrates a RESTful API that fetches the top movies of the week from The Movie Database (TMDB), displaying real-time trending content.

A machine learning component using an XGBoost model is also implemented to predict user churn based on behavioral and account data.
